
# 🍕 Pizza Ordering System

A desktop application built using **C# and Windows Forms** to simplify the pizza ordering process.

## Features
- Select pizza size.
- Choose crust type.
- Select dine-in or takeout.
- Customize orders with additional toppings.
- Calculate the total price dynamically.
- Confirm and reset orders.

## Technologies Used
- C#
- .NET
- Windows Forms
- Object-Oriented Programming

## Project Purpose
This project was developed to strengthen my C# programming skills and practice building interactive desktop applications using Windows Forms.
